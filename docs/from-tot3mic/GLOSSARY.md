# GLOSSARY

> Plain-English terms used in this project. No jargon without a definition.

- **Stone** — the model. The thing being worked. Cannot be trusted to work itself.
- **Adze** — the enforcement layer (code around the model). The blade that works the stone. (An adze is a traditional carving blade.)
- **Carve** — one of the eight structural mechanisms that turns a failure mode into something physically impossible.
- **Guarantee (G1–G5)** — a property the system must deliver. If any fails, the system is broken by definition.
- **Compaction amnesia** — the failure where context compression re-summarizes finished/abandoned work as "still to do," causing the agent to loop. The literal killer of the last system.
- **Self-eating seam** — any place the agent can rewrite its own rules, prompt, or hooks. The thing G2 exists to close.
- **Amendment protocol** — the (still-open) rule for how the human changes the constitution via a path the agent cannot author.
- **Middle path** — keep a substrate's good foundation, surgically remove and rebuild the failed layer. Between greenfield (rebuild all) and fork (paint over the mold).
- **Substrate** — the base system we build on. Open (O1): OpenCode (TS/Bun), Aider (Python), or greenfield.
- **Face** — a UI surface of the agent: TUI, web app, or CLI.
- **Totem / OpenCode** — the lineage this rebuilds from. OpenCode is TypeScript+Bun; `totem` was a renamed fork of it. Confirmed from source (not Go).
- **Umbreality** — a separate realm/project ("spark civilization") whose philosophy was borrowed into the old system and tangled into its structure. Being stripped in Phase 1; NOT part of TOT3MIC.
