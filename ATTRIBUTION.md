# Totem — Attribution

Totem is a fork of [OpenCode](https://github.com/anomalyco/opencode) (formerly `sst/opencode`), forked at v1.17.10.

**Upstream:** OpenCode — open-source AI coding agent
- Repository: https://github.com/anomalyco/opencode
- License: MIT (see `LICENSE`; the upstream copyright notice is preserved there)
- Authors: the opencode contributors (anomalyco / SST)

**Changes from upstream:**
- Renamed binary, packages, XDG paths and config schema URLs (`opencode` → `totem`)
- Behavioral constitution injected at the system-prompt level (`CONSTITUTION.md`, `totem/src/session/prompt/constitution.txt`)
- Structural enforcement layer ("carves") under `totem/src/enforcement/` — write guard, directive store, session STOP, response gate, and friends
- Local-first provider priority (e.g. an Ollama server on your LAN)
- Custom tools (fs_read/write/append) and the `cartridge` knowledge-packaging package

Totem is independent. Upstream changes are not pulled automatically.
